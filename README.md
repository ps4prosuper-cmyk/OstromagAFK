# Telegram RPG AFK — безкоштовний запуск через GitHub Actions

**Статус:** шаблон, який потрібно протестувати на реальному ігровому боті. Не гарантує цілодобову безперервну роботу чи точний час запусків.

## Що робить
- Кожні ~5 хвилин GitHub Actions запускає один цикл.
- Натискає «Досліджувати», якщо немає бою.
- Під час бою натискає тільки «Атака».
- Після перемоги за HP 1–119 робить паузу 5 хвилин.
- За HP 0 робить паузу 10 хвилин (має пріоритет над перемогою).
- За повідомленням про нестачу енергії чекає вказану кількість хвилин (або 5 хв, якщо час не зазначено).
- Зупиняється при неочікуваних помилках, відсутності кнопок або відповіді.
- Один запуск обмежений 18 діями / 160 секундами.

## Важливі обмеження
- GitHub Actions запускається за розкладом **із можливими затримками**. Тому паузи — мінімальні, не точні.
- Заплановані workflow можуть автоматично вимикатися після 60 днів без активності публічного репозиторію.
- Telegram може обмежити надто часті запити. Скрипт робить паузи й обробляє FloodWait.
- У публічному репозиторії зберігається тільки `state.json` із часом паузи та HP; **ніколи** не публікуйте сесію, API hash або коди входу.
- Гра може забороняти автоматизацію правилами.
- Не запускайте паралельно другий екземпляр скрипта.

## Налаштування

1. Створіть акаунт GitHub і **публічний** репозиторій, наприклад `telegram-rpg-afk`.
2. Завантажте в нього вміст цієї папки (включно з `.github/workflows/afk.yml`). Не додавайте секрети.
3. На своєму комп'ютері один раз встановіть Python і виконайте:
   ```
   pip install -r requirements.txt
   python create_session.py
   ```
4. На https://my.telegram.org у `API development tools` створіть застосунок і отримайте `api_id`, `api_hash`. Уведіть їх у `create_session.py`, підтвердьте вхід кодом Telegram і, за потреби, паролем 2FA. Скопіюйте отриманий **StringSession**.
5. GitHub → репозиторій → Settings → Secrets and variables → Actions:
   - вкладка **Secrets** → `New repository secret`: `TG_API_ID` (число), `TG_API_HASH`, `TG_SESSION` (довгий рядок).
   - вкладка **Variables** → `New repository variable`: `GAME_BOT` = username ігрового бота **без @**.
6. У Telegram вручну відкрийте гру, запустіть `/start` та залиште активною клавіатуру гри.
7. GitHub → Actions → `Telegram RPG AFK` → `Run workflow`. Подивіться журнал. Після перевірки працюватиме розклад.

## Зупинка
GitHub → Actions → `Telegram RPG AFK` → `...` → `Disable workflow`.
Для повного відкликання доступу видаліть сесію в Telegram → Settings → Devices (Пристрої).

## Діагностика
- `Explore button missing`: відкрийте гру вручну й перевірте текст кнопки.
- `Combat detected but attack button missing`: потрібен скриншот/текст конкретного етапу бою.
- `No new bot response`: перевірте обмеження гри або зміни в її інтерфейсі.
- `Missing ...`: перевірте назви GitHub Secrets та Variables.
- `Telegram session expired`: створіть нову сесію через `create_session.py`.
- Пауза не витримується: перевірте, чи GitHub має дозвіл на запис `contents: write` та чи успішний крок `Persist cooldown`.

## Безпека
StringSession дає доступ до вашого Telegram-акаунта. Зберігайте його тільки в GitHub Actions Secrets, не надсилайте в чат і не викладайте в файли репозиторію. Для першого тесту краще використовувати окремий Telegram-акаунт.
